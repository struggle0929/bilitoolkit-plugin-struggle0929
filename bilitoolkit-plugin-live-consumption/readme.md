# 直播消费账单

BiliToolkit UI 插件。通过主程序选择并授权本人已登录的哔哩哔哩账号，直接查询本人直播消费记录，整理电池支出、退款、主播分布和消费明细。

## 功能

- 按接口游标自动翻页获取当前可查的消费记录，支持更新最新记录、完整重查和中途停止。
- 显示净支出电池、付费消费记录数、礼物种类及主播数，按月绘制净支出趋势和主播分布。
- 按日期、主播昵称或 UID、礼物名称及流水号筛选；区分付费消费、包裹道具和退款记录。
- 按本人 UID 隔离保存本地账单缓存，导出当前筛选范围为 CSV 或 JSON。
- 显示最早/最新记录及查询完整状态，查询中断或接口异常时保留已取得的数据。
- 点击主播、礼物和月份联动筛选全部统计与明细；支持完整主播列表，包裹道具可按数量或记录数绘图。
- 独立读取盲盒开奖记录，按盲盒礼物 ID、主播和日期查询，展示结果礼物、配置概率、当前价格估算成本及礼物面值差额。配置下架仍尝试查询记录，未知价格不当作零价。
- 合成分析按可编辑的材料/产物名称及日期匹配，分开展示材料支出、已送出产物面值和当前库存；其他页面支持天选/红包分类及活跃日期、连续天数统计。
- 查询当前包裹、使用限制和到期时间。
- 本人主播查询包括收到礼物、近期 7 天直播场次、本场礼物和分段元数据；需要账号具有对应主播权限。

## 使用

1. 在哔哩工具姬的账号管理中登录本人账号。
2. 打开插件，点击“选择并授权账号”，完成宿主的账号授权。
3. 点击“查询消费记录”；已有缓存时可更新最新记录，也可选择“重新获取全部记录”。
4. 使用日期和关键词筛选，或点击主播图例、礼物和月份；“盲盒与更多查询”提供各类扩展查询。导出文件保存在本插件的本地文件目录，导出完成后会打开所在目录。

重新打开插件时会验证并复用此插件上次已授权的登录会话，不需要重复选择账号。登录失效时请重新授权；宿主通知账号退出时会清除此插件会话。

统计按电池展示。包裹道具和已退回记录不计入净支出，已识别退款从支付电池中扣除。消费次数按记录数计算，不等于礼物数量。所有日期按北京时间统计。

“已遍历接口返回的全部页”仅表示已读到 B 站接口本次可返回范围的末尾，并不保证覆盖账号注册至今的全部历史。此插件查询直播消费，不包含充值、微信/支付宝账单、大会员、会员购及其他业务；电池数不能直接当成人民币实付金额。旧记录发生退款等变化时，可使用“重新获取全部记录”校正本地账单。

账号登录通过哔哩工具姬完成，插件不要求手动填写 Cookie。插件自身的账单快照和导出文件不保存登录 Cookie。

盲盒的开出礼物与消费流水中的包裹道具是两套数据，不能互相替代。盲盒成本和面值差额依当前配置估算，不代表实际充值、现金收益或可提现金额；历史价格可能不同。合成没有独立的完整历史接口，分析属于规则匹配，不能证明每件包裹产物的真实来源。当前库存不混入历史统计，避免重复计值。

主播收礼单次查询最多 31 天，可选择更早区间分段查询；这是插件的单次请求范围，不是历史只保留 31 天。近期场次 7 天范围来自原程序回放查询逻辑，与本人消费历史范围无关。主播接口原始数值不擅自换算成人民币；回放仅展示分段元数据，当前不播放或下载视频。

本轮重新实现了查询页面，未复制原程序自动抽奖、发弹幕、关注、上传等操作，也未加入趣味评分/称号和保存图片。逆向依据与未验证事项见 [调查记录](./docs/reverse-engineering.md)。

## 本地开发

```powershell
pnpm install
pnpm check
pnpm test
pnpm build
```

在哔哩工具姬中以本地测试插件加载此目录的构建结果。开发服务使用端口 5176，启动命令为 `pnpm dev`。

独立包名：`bilitoolkit-plugin-live-consumption`。当前源码为 0.2.0，本次仅更新源码和本地构建，尚未发布 npm。
